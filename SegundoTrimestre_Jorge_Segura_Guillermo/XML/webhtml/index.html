Conceptos Clave de XML

XML (Lenguaje de Marcado Extensible) es un estándar del W3C diseñado para transportar y almacenar datos, no para mostrarlos. A diferencia de HTML, las etiquetas no están predefinidas.

  • Estructura: Basada en un árbol jerárquico con un solo nodo raíz.
  • Bien formado: Cumple reglas sintácticas como el cierre de etiquetas y distinción de mayúsculas.
  • Validación: Proceso para verificar si el archivo sigue las reglas de un DTD o XSD.

Sintaxis y Estructura

Un documento XML consta de un Prólogo (declaración de versión y codificación) y un Cuerpo (árbol de contenido).

Ejemplo de Elemento:

<libro paginas="450"> <titulo>Título del Libro</titulo> <autor>Nombre del Autor</autor> </libro>

Validación con DTD

La DTD (Definición de Tipo de Documento) establece las reglas de qué elementos y atributos pueden aparecer.

Símbolo Cardinalidad / Regla
? 0 o 1 vez (Opcional)
* 0 a muchas veces
+ 1 a muchas veces (Al menos uno)
(A|B) Elemento A o elemento B (pero no ambos)
