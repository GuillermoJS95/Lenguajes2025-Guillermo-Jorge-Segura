Conversión y Adaptación de Documentos XML

¿Qué es XPath? Es un lenguaje diseñado para navegar a través de los nodos de un árbol XML, permitiendo localizar elementos, extraer datos y realizar cálculos mediante rutas jerárquicas.

1. Lenguajes de Transformación (XSL)

El estándar XSL (Extensible Stylesheet Language) se divide en tres partes principales:

  • XPath: Localización de elementos en el árbol XML.
  • XSLT: Transformación del documento original a otros formatos como HTML o XML.
  • XSL-FO: Aplicación de estilos para formatos de impresión, comúnmente PDF.

2. El Árbol XML y su Sintaxis

XPath ve los documentos como una jerarquía de nodos: raíz (/), elementos, atributos (@) y texto.

//coche[@matricula="1234ABC"]/marca/text()
Símbolo Descripción
/ Selección desde la raíz.
// Selección en cualquier parte del documento.
@ Selección de atributos.
[] Predicados o condiciones de filtrado.

3. Formatos de Intercambio de Datos

Además de XML, existen otros formatos clave analizados en el curso:

  • JSON: Ligero, basado en pares clave-valor, muy usado en APIs.
  • CSV: Formato tabular simple separado por comas o delimitadores.
  • YAML: Basado en la indentación, ideal para archivos de configuración.
